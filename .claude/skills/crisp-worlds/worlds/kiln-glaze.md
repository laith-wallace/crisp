## Layout grammar

A grid of glaze-test tiles: small, equal squares of colour or product imagery, each with a code and a name, arranged like a studio wall. Long-form sections sit in a single calm column with large imagery between them.

## Signature moves

1. Test-tile grids where each tile has a code (T-14) and a name, for products, options or colourways.
2. Large, slightly irregular radii on imagery, as if hand-trimmed, kept consistent on controls.
3. Glaze teal for actions against warm clay, with terracotta and celadon as fills only.

## Avoid

- Beige with no hue; the clay must read warm.
- Drop shadows that look digital (hard, grey, offset).
- Script or handwritten type to signal "hand-made".

## In product UI

Brand register: crafts, homeware, food, wellness, small studios. In a shop or booking app, the tile grid suits variant pickers and class schedules; checkout stays plain with the teal action.
