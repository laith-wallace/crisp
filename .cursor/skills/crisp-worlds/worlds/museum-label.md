## Layout grammar

One object per view, placed off-centre with a large field of wall around it. The caption sits small, to the lower right of the object, in a fixed format: title, maker, date, material, then one or two sentences. Navigation is a quiet text line at the top.

## Signature moves

1. The caption block: title in light serif, details in small sans, in the same order every time.
2. Whitespace as the main material; at least half of each viewport is empty wall.
3. A single umber accent for links, so the page has almost no colour at all.

## Avoid

- More than one call to action per view. The visitor is looking, not shopping.
- Big type. The confidence comes from small, exact text.
- Carousels and auto-play, which treat objects as content to scroll past.

## In product UI

Brand register. It suits portfolios, galleries, premium product pages and case studies. In an app, borrow only the caption format for detail panels (title, metadata in a fixed order, one paragraph) and leave the empty wall behind.
