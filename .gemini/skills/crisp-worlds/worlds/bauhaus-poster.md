## Layout grammar

An asymmetric composition on a diagonal or strong vertical axis. One large geometric shape (a circle, a bar) anchors the page; type is set in blocks that lock to the shape's edges. Headlines can rotate 90 degrees along a vertical edge.

## Signature moves

1. One oversized primary shape per screen that the headline and content align to.
2. Lowercase geometric headings with tight leading, set in blocks rather than lines.
3. Red, yellow and blue used as solid fields, with blue as the action colour because it carries text at AA.

## Avoid

- Using all three primaries at equal weight; one dominates, one supports, one punctuates.
- Rounded corners, because they soften the geometry into a toy.
- Applying it to data-dense screens; the composition needs room.

## In product UI

Brand register. In a product, keep it to the marketing site, onboarding or an education surface. A dashboard in this world would use the primaries only as category colours in charts, with the geometry left behind.
