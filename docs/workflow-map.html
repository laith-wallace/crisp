Runs without you

Design detector and finish gate

After each UI file edit, it reports only the issues that edit added. Before the agent stops, it blocks on new P0 or P1 findings, on a suppression with no real reason, and on more than 5 suppressions. It keeps blocking while fixes land, up to 3 rounds. Run it by hand with npx @laith-wallace/crisp detect <path>.

Lessons log

When you correct a skill, it writes one line to .crisp/lessons.md. Every skill reads it before it starts. A rule that comes up 3 times is ready to move into the shared taste rules.

Taste bank

Save a great site with /crisp-study <url> --bank. Design skills read .crisp/taste-bank/ before they design and name what they borrow.

Taste test set

Five graded briefs in evals/graded/taste-*. Run them before and after you change a skill. If the pass rate drops, the change made the pack worse.

Render check

Measures the page as the browser draws it, at desktop and phone widths. crisp render-check <url> --width 1280,375. Exit 0 is clean, 2 has findings, 3 could not decide.
