# Brief: Diffline

- A code-review tool for teams on GitHub.
- It groups a pull request's changes by intent (refactor, behaviour change, test, config) so a reviewer reads behaviour changes first.
- Inline comments sync back to GitHub.
- Works with GitHub only. GitLab is not supported.
- Price: free for public repos; 12 USD per seat per month for private repos.
- Main action: start a 14-day trial.
- No customer quotes or usage numbers are cleared for use yet.
